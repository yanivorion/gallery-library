Gallery Library

Ninety-seven React galleries, each one compiled and run before it was listed.

Four Wix custom-element packs held 97 gallery, carousel and slideshow components as raw JSX. Every one was compiled with Babel, mounted in its own iframe against React 18.3.1, left to settle for 2.2 seconds and photographed. This page follows one of them, Bento Grid Gallery, from the pack JSON to its 12.1 KB of source.

Run

Nothing is listed on trust. Each component is transformed, mounted and watched until it settles, and whatever the console says is recorded next to it.

Seven stages, 97 times

The runner walks the four pack files, pulls each component's JSX, compiles it in the browser and mounts it into a blank iframe holding React 18.3.1 and nothing else. Median render was 905 ms; the slowest, Horizontal Scroll Carousel, took 1,382 ms.
