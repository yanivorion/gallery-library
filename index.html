Gallery Library

A hundred and thirteen React galleries, one typeface, eight photographs, no colour.

Four Wix custom-element packs held 113 gallery, carousel and slideshow components as raw JSX. Every colour in them was flattened to a 16-step grey ramp, every typeface set in Neue Haas Grotesk and every photograph replaced by one of eight. Each was then compiled with Babel, mounted against React 18.3.1 and captured. This page follows Bento Grid Gallery, from the pack JSON to its 12.1 KB of source.

Part I

Flatten

Three rules, applied to every file in the library by one script. Nothing was redesigned by hand.

One typeface, eight pictures, no hue

The packs arrived with their own palettes, their own system font stacks and 61 different stock photographs. All of it was rewritten in place: 226 component files, their prop schemas and the library UI around them.

Colour
Every hex, rgb and hsl value converted to its luminance and snapped to a 16-step grey ramp. 473 colour props among them.
Type
Every font stack replaced with Neue Haas Grotesk Display Pro, falling back to Helvetica Neue and then Arial. Enum values like “mono” left alone.
Image
Every remote photograph replaced by one of eight local files, cycling from a per-component offset so no two neighbours open on the same picture.
Part II

Run

Nothing is listed on trust. Each restyled component is transformed, mounted and watched until it settles, and whatever the console says is recorded next to it.

Seven stages, 113 times

The runner walks the four pack files, pulls each component's restyled JSX, compiles it in the browser and mounts it into a blank iframe holding React 18.3.1 and nothing else. Median render was 907 ms; the slowest, Z-Stack Gallery, took 1,020 ms.
